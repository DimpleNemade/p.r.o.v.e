# V0.1 scope

The [scope boundary diagram](diagrams/11-v0.1-scope-boundary.md) is normative for this
milestone. This document is its written form.

## In scope

| Capability | State in V0.1 |
| --- | --- |
| Cases, case detail, participants | controlled API; ordinary participant creation cannot grant ownership |
| Evidence registration + acquisition metadata | API + UI |
| SHA-256 verification (registration + on demand) | API + UI; mismatch and unreadable paths are blocking |
| Chain of custody | append-only; written on registration and verification |
| Processing jobs + runs | API + UI; synchronous eager mode locally, Celery/Redis for teams |
| Normalized artifacts (basic file metadata) | produced by the `basic-metadata` processor |
| Artifact search | substring query over artifact content |
| Timeline events | model + created by processing; no dedicated endpoint yet |
| Provenance links | model + API; created by processing |
| Bookmarks, investigator notes | models only |
| Findings + supporting evidence | API + UI for findings; support attach via API |
| Audit trail | append-only; written on every material action |
| Report drafts | API + UI; assembled from findings + provenance |
| Controlled export | real create/status/download package with offline verifier |

## Out of scope (deliberate)

Mobile, live-endpoint, remote, and cloud acquisition; memory, network, and malware
forensics; complete parser coverage; autonomous criminal or attribution conclusions;
threat-intelligence ingestion; any external AI call; destructive evidence operations;
a graph database; billing; and full training/education workflows.

These are excluded because each needs its own intended-use definition, validation
tranche, threat model, and governance. See [ADR-008](decisions/008-v01-exclusions.md).

## Known gaps within scope

Tracked honestly so they are not mistaken for finished work:

- no endpoint to add/remove case participants, timeline events, notes, or bookmarks;
- object-not-found on detail routes returns `500` rather than `404`;
- React Router drives the case workspace. React Query remains available but the current
  refresh coordinator uses explicit stale-request guards and stable selected IDs.
- The isolated E2E journey covers investigator processing, independent review, report,
  package download and audit history.

See [19 Phase 0 gap analysis](19-phase-0-gap-analysis.md) for the full list and how it
maps to the programme's foundation gate.
