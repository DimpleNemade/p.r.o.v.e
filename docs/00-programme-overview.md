# Programme overview

This programme creates P.R.O.V.E, a provenance-first investigation workspace. V0.1 is a foundation for controlled evidence registration, verification, processing, review, and reporting. The primary stakeholders are investigators, supervisors, reviewers, auditors, and engineers.

Success means that each important output can be followed back to registered source evidence, while an examiner remains responsible for interpretation and conclusions.

See [scope](02-v0.1-scope.md), [architecture](03-system-architecture.md), and [product constitution](01-product-constitution.md).
